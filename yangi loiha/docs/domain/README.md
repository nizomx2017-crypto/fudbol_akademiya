# Domain Documentation

Bu papkada Pharmacy Management System domain kontekstidagi hujjatlar joylashadi.

## Core Domains

### Inventory Domain
- Dori-darmonlar inventarizatsiyasi
- Batch va expiry tracking
- Stock level monitoring

### Supply Chain Domain
- Yetkazib beruvchilar boshqaruvi
- Purchase order management
- Delivery tracking

### Sales Domain
- Sotuv jarayonlari
- Customer management
- Payment processing

### Compliance Domain
- Regulatoriy talablar
- Quality control
- Audit trail
