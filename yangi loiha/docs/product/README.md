# Product Documentation

Bu papkada Pharmacy Management System product kontekstidagi hujjatlar joylashadi.

## Product Vision
Dori-darmonlarni taqsimot, ombor nazorati va logistika jarayonlarini to'liq avtomatlashtirish.

## User Stories
- Dorixona egasi uchun inventar boshqaruvi
- Omborchi uchun yetkazib berish monitoringi
- Menejer uchun hisobotlar va analiz

## Features
- Real-time inventory tracking
- Automatic reorder notifications
- Supplier management
- Sales analytics
- Barcode scanning
